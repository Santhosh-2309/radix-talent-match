# Design Guidelines

## Theme
- Dark Theme

## Colors
- Background: Near-black (`#0a0a0a`)
- Accent: Amber/Gold (`#d4a04c`)
- Text: Off-white / Light Gray

## Typography
- Clean sans-serif (e.g., Inter or standard system fonts)

## Layout
- Minimal design, no heavy design system. Use basic spacing rules and color tokens.
