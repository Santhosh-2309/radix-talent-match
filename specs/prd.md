# RADIX Talent Match - PRD

## Purpose
A candidate-facing skill-matching app that allows candidates to match their skills to job descriptions.

## Scope
Built solo as a 5-hour hackathon project for handoff to 2 teammates who own Talent Check + Skill Matching.

## Modules
1. **JD Analytics**: Parse and extract skills from a Job Description.
2. **Resume Parsing**: Parse and extract skills from a candidate's Resume.
3. **Profile Builder**: Build and save candidate profiles.
4. **Talent Check**: Score a candidate profile against a company's general requirements.
5. **Skill Matching**: Match candidate skills directly against a specific Job Description.
